# VoxVer Launcher v0.7.3 发布说明

> 发布日期：2026-09-26 ｜ Tag：`VoxVer-v0.7.3` ｜ 上一版本：v0.7.2

## 下载

| 文件 | 说明 |
|------|------|
| `VoxVer-Launcher-Setup-0.7.3.exe` | Windows x64 安装包（NSIS，可选安装目录、快捷方式） |
| `VoxVer-Launcher-0.7.3.exe` | Windows x64 便携版（单文件，免安装） |

系统要求：Windows 10 及以上 x64。覆盖安装即可，实例与账户数据（`%APPDATA%/voxver-launcher`）不受影响。

## 独立版本更新页

本版本将更新功能从设置页抽离为独立的全屏页面（路由 `/update`），设置页「检查更新」按钮直接跳转进入：

1. **横幅**：Logo + 当前版本号 + 状态胶囊（检查中 / 已是最新版本 / 有新版本可用），背景为零依赖 WebGL 丝绸水波纹动画（`SilkBackground`，颜色跟随主题色）
2. **更新内容区**：渲染 GitHub 最新 Release 的发布说明（Markdown，转义 + 白名单过滤）
3. **底部操作栏**：检查更新 / 下载更新 / 取消下载 / 安装更新 / 前往 GitHub Releases
4. **顶栏**：返回按钮 + 拖拽移动区 + 窗口最小化/最大化/关闭

### 下载与安装

- 进度条实时显示已传输/总大小与速度（MB/s）
- 下载支持随时取消（`CancellationToken`），取消后状态即时复位
- 检测到更新后状态可恢复：退出重进更新页仍可继续下载或安装
- 检查更新沿用双链路仲裁：GitHub API 版本对比结论优先，`latest.yml` 滞后时以 API 结论兜底

### 修复

- 设置页「检查更新」按钮点击无反应
- 已是最新版本时无任何提示
- 下载过程无状态反馈

### 其他

- `builder-util-runtime` 固定 9.5.1 精确版本，与 electron-updater 内嵌副本同源，修复跨副本 `CancellationToken` 失效

## 升级指南

从 v0.7.2 直接覆盖安装即可。也可以在应用内「设置 → 关于 → 检查更新」检测本版本并在线升级。
