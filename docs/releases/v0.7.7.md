# VoxVer Launcher v0.7.7

这一版的主线是**「Koring 排版」**：给启动器加了一套全新的卡片式界面皮肤，可以在设置里一键切换，原有的 VoxVer 原版排版完整保留。

## 新增

### Koring 排版皮肤

- **主题预设**：设置 → 主题与背景 → 主题预设，可在 **VoxVer 原版** 与 **Koring 卡片排版** 之间切换；切换时弹确认并自动重启生效
- **显示模式与排版解耦**：浅色 / 深色 / 跟随系统只控制明暗，排版皮肤独立存储（`voxver_theme` / `voxver_skin`），可以自由组合；旧版 `theme=koring` 数据自动迁移
- **自建 Kor 组件层**：UI 原语、设置原语、`KorPageShell` 页面外壳、`KorSilk` 丝绸层、`KorVersionCard` 版本横幅等，不引入 three.js / Tailwind
- **Koring 覆盖范围**：设置页全部分类、下载页与下载管理、首页、实例页、启动页、更新页、账户页、版本页 / 版本详情、Mod 详情页、崩溃分析页

### 首页

- 满屏主色背景 + 大写 V 水印，左上角账户卡，左下角显示当前版本名
- 鼠标移到版本名上会整体上移，「启动游戏」胶囊从下方滑出；点击版本名进入实例页

### 实例页

- 数据来源改为「设置 → 游戏目录」里配置的 `.minecraft` 目录，不再读取系统盘里的陈旧实例
- 左栏按游戏目录分组（显示版本数量），右栏列出该目录下已安装的版本
- 记住上次选择的游戏目录与版本，从别的页面回来仍是同一个目录、同一个选中项
- 单击版本即选中并回到启动页，双击直接启动
- 同一条安装链（原版 → Forge → OptiFine）在列表里合并成一张卡，名称显示完整安装名，例如 `1.18.2-forge-40.3.12-OptiFine_HD_U_H9`

### 更新页

- 底部改为固定操作栏：状态行 + 主按钮 + 下载进度，对标 Koring Launcher
- 向下阅读更新说明时底栏自动收起，向上滚动或回到顶部恢复；检查 / 下载过程中强制常显
- 更新说明正文加大行距与卡片间距，长文更好读

### 界面

- 顶部导航改成滑动胶囊指示器，切换时平滑过渡，两套皮肤各自配色
- 标题栏与页面底色统一为主题色，全站共享天蓝主色 + V 水印背景
- 滚动条默认隐藏，悬停才显示

## 修复

- **版本下载与加载器安装**：修复 Forge / NeoForge / Fabric 安装与版本下载链路上的问题
- **页面切换空白**：移除 `mode="out-in"` 的路由过渡，修复离开首页后主内容区不渲染
- **实例目录**：修复目录显示与文件监听
- **版本搜索**：在下载页搜索框输入版本号后回车，会自动展开命中的分组（正式版 / 预览版 / 远古版 / 愚人节版）并滚动到该版本
- **更新页细节**：去掉重复的标题块与重复的状态文案，返回按钮移到左上角，内容宽度限制在 980px 并留出左右边距

## 系统要求

Windows 10 及以上 x64。覆盖安装即可，实例与账户数据（`%APPDATA%/voxver-launcher`）不受影响。
