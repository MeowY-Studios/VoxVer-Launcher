# VoxVer Launcher v0.6.0

**发布日期**：2026-06-28

## 概述

本次更新为 VoxVer Launcher 带来了设置页面的全面重构、全局 UI 控件统一、以及完整的主题系统升级。

## UI 重构

### 设置页分类拆分
- 设置页面按功能分类拆分为多个子页面，提升导航效率与可维护性

### 控件统一
- 全局 UI 控件使用 `.vox-*` 类前缀（`.vox-btn`、`.vox-input`、`.vox-card` 等），统一样式规范

### 主题系统重构
- 浅色/深色主题完整切换
- 背景自定义功能
- 主题色自定义功能

## 升级指南

从 v0.5.x 升级的用户：
1. 启动器会自动迁移配置，无需手动操作
2. 如遇主题异常，可在「设置 → 外观」中重置主题
3. 全局控件样式已统一，自定义皮肤可能需要适配 `.vox-*` 类名
