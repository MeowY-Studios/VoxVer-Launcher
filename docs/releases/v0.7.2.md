## 更新检查双链路

本版本重构了「检查更新」功能，形成检测 + 执行两条互相衔接的链路：

1. **版本对比链路（GitHub API）**：点击检查更新或启动时自动检查，直接调用 GitHub API 获取最新 Release 版本号，与本地版本逐段比较（支持预发布后缀），**不再依赖 `latest.yml` 元数据**
2. **更新执行链路（electron-updater）**：检出更新后自动准备下载元数据；点击下载时若元数据未就绪会自动补检；下载完成后可一键重启安装

### 检查更新的可见反馈

- 有新版本：弹「新版本可用」弹窗，显示新版本号，可下载更新
- 版本一致：弹「已是最新版本」弹窗，显示当前版本号
- 检查失败：弹错误详情弹窗
- 按钮在检查期间禁用并显示「检查中...」，12 秒无响应自动恢复
- 启动时的自动检查结果在设置页可恢复展示

### 其他

- `latest.yml` 滞后时以 API 对比结论为准，避免下载按钮被错误禁用
- 开发模式下版本检测同样可用
- `build-demo/` 构建产物加入 .gitignore

## 升级指南

从 v0.7.1 直接覆盖安装即可。也可以在应用内「设置 → 关于 → 检查更新」检测本版本并在线升级。
