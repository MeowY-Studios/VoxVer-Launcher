# VoxVer Launcher v0.7.6

## 新增

- **独立启动画面**：启动时先出现无边框 splash 窗口——草方块落地（带扬尘与光圈）→ VOXVER 像素字 → 像素进度条 → 状态文案，主窗口就绪后播放退场动画再销毁。不再「先黑屏、窗口出现后再空等 4 秒假进度」
- **晴空草原配色**：启动画面从深色科技风改为浅蓝天空 / 奶油地平线 / 像素云 / 草地条，草方块落在左下草地上；跟随系统「减少动态效果」时自动降级为静态
- **应用图标重做**：字标改为 V 记号图标——天蓝渐变底 + V 对角渐隐到透明。`resources/icons/icon.svg` 作为唯一矢量源，`node scripts/generate-icons.js` 一键产出 16–1024 全尺寸与多尺寸 ICO
- **CI 类型检查**：新增 `npm run typecheck`（node + web 双配置）并接入 CI，打包 job 依赖 lint / typecheck / test 全绿

## 修复

- **存储型 XSS（S-01）**：设置页更新说明原用自写净化函数 + `v-html`（不转义引号、不限制链接协议，可注入属性或 `javascript:`），改为受控 Markdown 渲染器，仅放行 `http(s)` 链接
- **命令注入（S-02）**：Java 检测与查找原先用 `execSync` 拼接路径，改为参数化 `spawnSync` + 参数数组，路径不再进入 shell
- **任意文件读写（S-03）**：截图 / Mod / 对话框相关 IPC 原先直接信任渲染端路径，改为白名单根目录 + 扩展名 + 路径分段校验
- **潜在运行时错误**：`LaunchPage.vue` 调用未定义函数（点崩溃报告会抛错）、`InstanceDetail.vue` 同元素 v-else + v-if、`PxConfirm.vue` 无效 Transition、`perf-monitor.ipc.ts` 从未赋值的死缓存
- **CI 从未生效**：工作流级使用 `${{ runner.os }}` 导致整份 workflow 无效，自 v0.7.5 起的发布实际都没跑过构建；改为 step 级上下文与真实缓存目录

## 优化

- **类型与 lint 门禁清零**：7 处 tsc 错误、135 处 ESLint 错误全部清除；ESLint 忽略生成产物与外部技能目录，全量检查从 21 分钟降到 29 秒
- **依赖解析**：新增 `.npmrc` 开启 `legacy-peer-deps`，解决 electron-vite / plugin-vue 对 Vite 8 的 peer 冲突，`npm ci` 不再失败
- 主窗口内旧的页内 splash 与假进度条一并移除，启动链路只剩一个画面

## 系统要求

Windows 10 及以上 x64。覆盖安装即可，实例与账户数据（`%APPDATA%/voxver-launcher`）不受影响。
