# VoxVer Launcher v0.7.1

**发布日期**：2026-09-26

## 概述

v0.7.1 是 v0.6.4 之后的首个发布版本（含已在代码库完成的 v0.7.0 全部内容），累计 65 次提交。本次更新以 **XMCL 启动核心集成**、**崩溃分析系统** 和 **Lumin UI/UX 设计系统合并** 为核心，同时带来完整的 ModLoader / Mod 生态、实例自动导入、P2P 分享与大规模 i18n 补全，并修复了打包版本中关于页空白的严重问题。

## 新增功能

### 崩溃分析系统

- 游戏异常退出后自动扫描 `crash-reports` 并解析报告，内置 10 类崩溃特征匹配
- 新增独立「崩溃分析」页面（路由 `/crash-analysis`）：历史报告列表、严重程度标签、异常类型、可能原因、建议解决方案与完整堆栈
- 启动页崩溃卡片实时展示本次崩溃详情，可一键关闭

### XMCL 启动核心与 ModLoader

- 基于 `@xmcl/*` 工具链重写启动流程：修复 1.16 崩溃、1.20.1 Forge 自包含（无 inheritsFrom）版本启动
- Java 版本按 MC 版本自动选择：1.16- ≤ Java 11，1.17 ≤ 17，1.18–1.20.4 ≤ 21，1.20.5+ ≤ 25
- LWJGL 2（1.17 及以下）使用 `java.exe`，LWJGL 3（1.18+）使用 `javaw.exe`
- Forge / NeoForge / Fabric 一键安装，三者互斥切换时自动清理附加组件
- OptiFine 自动作为 Forge/NeoForge 附加件；Fabric API 从 Modrinth 自动匹配兼容版本
- 动态版本命名：`[游戏版本]-[加载器]_[版本]-[OptiFine]_[版本]`
- Java 16+ 自动注入 `--add-opens`，避免 `InaccessibleObjectException`

### Mod 管理与下载

- CurseForge + Modrinth 双源搜索与下载，Pinia Store 状态管理
- 批量操作、兼容性检查与角标、排序、本地 Mod 图标缓存、导出 zip
- 下载多源切换（默认 BMCLAPI 国内镜像）与超时控制
- 全局下载进度面板，IPC 实时进度推送

### 实例与联机

- 自动扫描当前 .minecraft 目录版本，可一键导入为托管实例
- 选择游戏文件夹后自动导入全部检测到的版本
- P2P 实例分享：6 位分享码 + WebRTC 直连收发实例包
- 设置侧栏拆分「P2P 分享」与「联机」独立入口

### 设计系统与 UI/UX

- 合并 [Lumin UI/UX](https://github.com/MeowY-Studios/Lumin-UI-UX)：Modal（4 档尺寸 + 响应式）、Toast（4 状态）、Badge 渐变变体
- 新增 modal-in/out、overlay-in/out 关键帧与过渡工具类
- 新增 PxSelect 组件统一替换原生下拉框
- 全局颜色 Token 化：`--voxver-*` CSS 变量 + `color-mix(in oklab, ...)`
- 页面切换统一 250ms 淡入淡出（enter translateY(8px) / leave translateY(-4px)，ease）

### 国际化

- 修复 560+ 处硬编码中文文本，新增约 300 个 locale key，覆盖 33 个文件
- 中英文双语完整对齐（含崩溃分析、下载状态、设置分区等新模块）

## 修复

- **【重要】关于页在打包版本中空白**：i18n 词条 `settings.aboutSection.xmclRole` 中的 `@xmcl` 被 vue-i18n 当作链接消息（linked message）语法解析，生产构建抛出 `SyntaxError: Invalid linked format` 并导致整个设置组件卸载；已用 `{'@'}` 字面量语法转义（zh-CN / en-US 同步修复）
- JVM 参数不再用 `Set` 去重，保留全部 `--add-opens`，修复 Forge/OptiFine 的 `ClassNotFoundException`
- 统一使用 G1GC，移除 Java 14+ 已删除的 CMS GC 选项
- 类路径条目去重，修复 `Duplicate key` 错误
- 版本号提取正则锚定字符串开头，避免从整合包名（如「你好，新蒸程！V1.4.2」）误提取
- 游戏进程 stdout/stderr 全量捕获（`[Game-STDOUT]` / `[Game-STDERR]`），非零退出时转储最后 200 行
- BMCLAPI 302 重定向导致的 0 字节下载（跟随重定向）
- 多处硬编码颜色替换为 CSS 变量，深色/浅色主题切换不再出现色块
- `color-scheme` 统一为 `dark light`，修复原生下拉框/输入框配色
- 清空游戏目录后同步清除上次选择版本，修复启动按钮显示失效版本
- 补全 DownloadStatus 的 `queued` / `error` 类型映射与多语言词条
- ReceiveModal / ShareModal 缺失样式与导入修复

## 升级指南

从 v0.6.4 升级的用户：

1. **安装包覆盖安装即可**，数据库（实例、账户、配置）位于 `%APPDATA%/voxver-launcher`，不受影响
2. 新增「崩溃分析」页面；游戏崩溃后启动页将自动展示解析结果
3. 设置侧栏中「P2P 分享」与「联机」已拆分为两个独立入口
4. 首次使用 ModLoader 安装功能时会按所选 MC 版本自动匹配 Java，无需手动指定
