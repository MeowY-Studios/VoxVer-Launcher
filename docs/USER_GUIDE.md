# VoxVer Launcher 用户手册

> 适用版本：v0.7.3 ｜ 面向玩家的完整使用说明

---

## 安装与首次启动

1. 前往 [GitHub Releases](https://github.com/MeowY-Studios/VoxVer-Launcher/releases) 下载安装包：
   - `VoxVer-Launcher-Setup-x.x.x.exe`：安装版，支持自定义安装目录
   - `VoxVer-Launcher-x.x.x.exe`：便携版，单文件免安装
2. 系统要求：Windows 10 及以上（x64）
3. 首次启动后进入主页，此时还没有游戏版本，需要先完成 [登录](#账户登录) 与 [版本下载](#下载游戏版本)

数据目录：`%APPDATA%/voxver-launcher`（账户、实例、配置均存于此，覆盖安装/升级不会丢失）

---

## 账户登录

支持两种方式，入口在左侧边栏「账户管理」：

**微软正版登录（推荐）**

1. 点击「微软登录」，启动器会显示一个设备码与跳转链接
2. 在浏览器打开 `microsoft.com/devicelogin`，输入设备码并完成授权
3. 授权完成后自动返回，Token 由系统凭据管理器加密保存，后续启动自动续期，无需重复登录

**离线模式**：输入用户名即可创建离线账户，适合单机体验；部分需要正版验证的服务器无法进入。

多账户可自由切换当前激活账户，皮肤信息随账户展示。

## 下载游戏版本

入口在左侧边栏「版本管理」：

1. 版本列表来自 BMCLAPI 国内镜像，分为正式版 / 快照版 / 远古版，可按类型筛选
2. 选择目标版本进入详情页，点击安装；下载源自动在官方源与 BMCLAPI 间切换，进度实时显示
3. 安装完成后版本出现在「启动」页，选择版本点击启动即可进入游戏

Java 无需手动安装：启动器按游戏版本自动选择 Java 8 / 11 / 17 / 21 / 25（1.17 以下用 `java.exe`，1.18+ 用 `javaw.exe`）。

---

## ModLoader 与 Mod

**安装 ModLoader**：在版本详情页选择 Fabric / Forge / NeoForge / Quilt 一键安装；已装其它 Loader 时会自动互斥切换。OptiFine 与 Fabric API 会自动匹配兼容版本。

**下载 Mod**：入口在左侧边栏「下载」，聚合 CurseForge 与 Modrinth 双源搜索：

- 按游戏版本、Loader 类型、分类筛选，查看下载量与兼容性角标
- 进入资源详情页选择适配文件，下载到指定实例
- 支持整合包、资源包、光影包的同源下载

**管理 Mod**：在实例详情页可启用/禁用/删除 Mod、查看磁盘占用、管理资源包与光影包、备份存档。

## 实例系统

实例 = 一套独立的游戏目录（版本 + Mod + 配置 + 存档）。

- **创建**：在「实例」页新建，或把已下载的版本导入为托管实例
- **切换**：启动页选择实例即切换整套游戏环境，互不污染
- **导入导出**：实例可导出为 `.mcla` 文件分享给别人，也可从 `.mcla` 导入还原
- **P2P 分享**：生成 6 位分享码，好友输入分享码后通过 WebRTC 直连传输实例，无需网盘

## 个性化设置

入口在左侧边栏「设置」：

| 设置项 | 说明 |
|--------|------|
| 主题与背景 | 显示模式（浅色 / 深色 / 跟随系统）、**主题预设**（VoxVer 原版界面 / Koring 卡片排版，切换后自动重启）、主题色预设与自定义主色、背景图与模糊/暗化/视差 |
| 显示 | 字号、动画开关、特效与音效 |
| 语言 | 中文 / English |
| 游戏 | .minecraft 路径自定义、内存分配、JVM 参数 |
| 账户 | 多账户管理与激活 |
| 下载与网络 | 服务联通性测试、下载源策略、并发数与限速 |
| P2P / 联机 | 分享码与联机分区设置 |
| 快捷键 | 全局快捷键：启动游戏 / 打开主页 / 打开设置 / 显示隐藏窗口 |
| 备份 | 配置备份与迁移 |

### 主题预设（VoxVer / Koring）

「设置 → 主题与背景」里有两块互不影响的内容：

- **显示模式**：浅色 / 跟随系统 / 深色，只改变界面明暗。
- **主题预设**：选择整套界面排版 —— **VoxVer**（原版布局）或 **Koring**（Koring Launcher 风格的卡片排版）。选择后弹确认框，确认即自动重启启动器生效；两套排版各自记住当前的明暗模式。

卡片下方的「自定义主题颜色」提供预设色板与「自定义」入口：选预设或输入色号后，主色阶梯预览会立刻按该颜色变化，点「应用」才真正写入并使用。

## 下载与网络

入口在「设置 → 下载与网络」：

| 设置项 | 说明 |
|--------|------|
| 服务联通性测试 | 进入后列出下载源、版本源、Mod 平台、登录与更新共 10 项服务；点击右上角「开始检测」才发起探测，逐项显示在线状态与延迟 |
| 下载源选择策略 | 自动选择 / 官方源优先 / 镜像源优先，直接作用于实际下载链路 |
| 同时下载数 | 同时进行的文件下载数量 |
| 最大下载线程 | 开启为自动选择；关闭后可手动设置单文件线程数 |
| 下载速度限制 | 开启为不限速；关闭后可手动设置限速值 |
| 最大重试次数 | 开启为自动；关闭后可手动设置重试次数 |

**下载源策略怎么选**

- 网络正常：保持「自动选择」，官方源与镜像源会自动择优
- 国内网络下载慢：选「镜像源优先」，优先走 BMCLAPI 镜像
- 需要绝对官方文件：选「官方源优先」

## 崩溃分析

游戏异常退出时，启动器自动捕获崩溃日志并识别 10 类常见崩溃特征（内存不足、Java 版本不匹配、Mod 冲突等）：

1. 启动页会弹出崩溃面板，展示错误描述、可能原因与建议解决方案
2. 完整历史在「崩溃分析」页查看，含严重程度与堆栈详情

---

## 应用更新

入口在「设置 → 检查更新」（跳转独立更新页）：

- 横幅实时显示状态：检查中 / 已是最新版本 / 有新版本可用
- 有更新时可直接查看发布说明、下载（显示进度与速度，可取消）并一键安装
- 退出重进更新页，下载/安装状态可恢复

## 常见问题

**启动游戏卡在下载文件**
下载源会自动在官方源与 BMCLAPI 间切换；网络受限时重试即可，进度面板可查看单个文件状态。

**Forge 版本启动失败**
v0.7.1 起已重写启动核心（XMCL 工具链），请确认升级到最新版本；1.20.1 Forge 需使用自包含版本。

**微软登录一直转圈**
设备码 15 分钟内有效，超时请重新获取；确认系统代理未拦截 `login.microsoftonline.com`。

**游戏闪退**
打开「崩溃分析」页查看自动生成的报告，按建议处理（最常见：内存分配不足或 Mod 与 Loader 版本不匹配）。

**英文界面出现 `time.minutesAgo` 之类的字样**
v0.7.3 质量修复批次已修复全部文案键缺失问题，请更新到包含该修复的构建。
